Core Design Philosophy

Everything inside the application should be configuration driven.

No page should contain hardcoded text.

No page should contain hardcoded images.

No page should contain hardcoded videos.

No page should contain hardcoded buttons.

No page should contain hardcoded cards.

Instead,

Store everything inside JSON configuration.

Pages should simply render configuration.

Example:

Page
    ↓
Sections
    ↓
Components
    ↓
JSON Data
